How it works

  1. PWA at this URL is the backup/source — empty start, first Android POST seeds TiDB (gateway01.ap-southeast-1.prod.aws.tidbcloud.com).
  2. Android keeps local Room DB for sending (no relay at send time).
  3. Sync: daily WorkManager + Sync now in Android Settings/Main.
  4. Archive (not hard delete) on both PWA and Android.
